# OBSIDIAN
Obsidian Shall Rise Again

## Overview
Obsidian is a web application designed with a dark, elegant aesthetic, featuring a gradient-based UI, particle effects, and a loading screen with animations. The project utilizes CSS custom properties for theming, animations for visual feedback, and a structured HTML layout for authentication screens (login/register).

## Features
- **Theming**: Dark mode with custom color variables (`--void`, `--obs`, `--gold`, etc.) for consistent styling.
- **Animations**: Particle drift, loading spinner, and glow effects for interactive elements.
- **Responsive Design**: Mobile-first approach with smooth scrolling and full viewport coverage.
- **Authentication UI**: Styled login/register forms with gradient text, input fields, and a decorative seal element.

- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Custom properties, animations, and responsive design.
- **Google Fonts**: `Cormorant Garamond` and `Courier Prime` for typography.

## Setup
1. Clone the repository:
  ```bash
  git clone https://github.com/fav-pixel/obsidian.git
  ```
2. Open `index.html` in a browser to view the application.
